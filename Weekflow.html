Quick guide

Weekflow 使用说明

这是一款 Multi-task 管理的座舱程序，具备多任务进度管理、任务相关资料汇总整理的功能。

主要功能

  • 时间轴看板：主界面 Task by Week 按自然周查看 Task DDL；双击任意周表头进入 Task by Day，只显示该周 DDL，并按周一至周日精确落到具体日期。日视图通过“返回 Task by Week”回到周时间轴。
  • Task 管理：创建和编辑 Task，可记录进度、完成状态和相关资料；紧急程度、汇报对象和交付物为必填项，汇报对象与管理对象均按人员姓名录入。周期可选每周或每月，需指定周期开始和结束日期。
  • 周期 DDL：周期 Task 仍只统计为一条 Task，但时间轴会按基准 DDL 的星期或日期显示多个 DDL；勾选本期完成会同时视同此前各期完成，下一周期自动恢复未勾选并保留之前的连续完成记录。
  • Flow 工作流：在分组和 Task 之间增加可选步骤层，支持拖动排序；新 Flow 默认继承所属分组颜色。
  • DDL 提醒：每次进入程序会在右下角播报未来 7 天内的未完成 Task，10 秒后自动关闭，悬浮时不影响页面操作。
  • 筛选与看板：时间轴可按分组、Flow、状态、紧急程度、逾期或关键词组合筛选；筛选弹层会在切换菜单或点击空白处时关闭。整体看板常驻显示 Task 总数、已完成、未完成、当前逾期和完成率，并可按分组、Flow、管理对象或汇报对象切换查看详细进度。
  • 对象汇总与导出：整体看板按人员姓名分别汇总每个管理对象和汇报对象的完成率、已完成、未完成及逾期数量，并一键导出该人员的 Task 状态。
  • Excel 批量录入：20 列 Task 模板包含周期、周期起止和完成历史，可下载空白模板或按模板下载当前数据，上传后先校验预览，再选择补充导入或完整覆盖。
  • 资料库：统一管理说明文档、交付物、控制表和文件夹，并提供 List 与 Group 两种布局。List 保留完整大列表和类型、分组、Flow、Task 筛选；Group 按 Task 分组显示固定高度资料栏，仅保留名称搜索和类型筛选。
  • Group 布局：默认每行显示四个分组，资料按本自然周与上个自然周的打开次数降序排列，同次数按名称排序；点击资料名称编辑，点击“前往”打开链接。可在“调整布局”中选择每行 1–4 个分组并拖动排列顺序。
  • 最近常用：List 可筛出本自然周或上个自然周至少打开过一次的资料；Group 会自动把近期打开次数更多的资料排在前面。
  • 资料导入与清理：资料 Excel 可选择补充导入或全部覆盖；重复地址可替换或跳过，批量删除需连续确认两次。

数据保存位置

数据保存在当前浏览器、当前页面来源的 localStorage 中，主数据键为：

weekflow-v2.4:data:v3

v2.6 为避免升级时迁移或清空既有数据，继续沿用 v2.4 兼容存储键。

清除浏览器网站数据、使用无痕窗口、更换浏览器或更换启动地址，都会影响可见数据。

数据备份与恢复

  1. 点击顶部数据操作区的 •••。
  2. 选择“导出 JSON 备份”，将文件保存到安全位置。
  3. 需要恢复时选择“从 JSON 恢复”，程序会先校验数据并请求确认。

建议在批量修改、迁移浏览器或清理网站数据前先导出 JSON 备份。

JSON 备份同时保存资料库的 List / Group 模式、每行分组数和分组排列顺序，恢复后会继续沿用原布局偏好。

Excel 批量导入

  1. 点击顶部数据操作区的 •••，下载空白 Excel 导入模板，或选择“按导入模板下载当前数据”。
  2. 在“Task导入”工作表中填写或调整数据，每行代表一条 Task。
  3. 选择“上传 Excel 批量导入”，检查错误提示和数据预览。
  4. 选择“补充导入”或“完整覆盖”，确认无误后执行导入。

不存在的分组和 Flow 会自动创建；已有同名项会复用。Flow 颜色留空时默认继承分组颜色。

周期可选不重复、每周或每月；周期 Task 必须填写起止日期。“周期完成记录”用于完整回导历史，手工新建时可留空。

补充导入保留现有时间轴数据并新增 Task；完整覆盖会连续确认两次，以文件替换全部分组、Flow 和 Task。资料库条目不会删除，同名层级会尽量沿用原 ID 以保留关联。

分组、Task name、DDL、紧急程度、汇报对象和交付物均为必填字段。

Excel 导出

点击“导出看板报告”会生成包含“整体看板”和“时间表看板”的 .xlsx 文件。

文件包含全部 Task、分组和 Flow 统计、步骤序号、周期及起止日期、进度记录、DDL 周时间轴与完整链接；周标签会区分已完成、逾期和待完成，不受当前筛选条件影响。

看板报告用于阅读与汇报，不作为批量导入文件；需要再次上传时，请使用“按导入模板下载当前数据”。

整体看板的“管理对象”和“汇报对象”模块支持按单个对象导出 Task 状态；文件只包含该对象的 Task，并按分组排序，带出 DDL、完成状态、紧急程度、进度记录、交付物及相关资料等基本信息。

资料库的“下载”菜单包含空白模板和全量资料清单，“上传”用于导入 Excel。

Weekflow 更新日志

v2.6 资料库双布局版 2026-08-14

在保留原 List 资料清单的基础上，增加按 Task 分组组织资料的 Group 布局及可持久化布局偏好。

新增与调整

  • 资料库新增 List / Group 双布局切换；List 的表格、筛选、上传下载和编辑逻辑保持不变。
  • Group 默认每行四栏，每栏对应一个 Task 分组并采用固定高度、组内独立滚动；资料仅展示名称、复选框和“前往”链接按钮。
  • Group 内资料按本自然周与上个自然周打开次数降序排列，同次数按名称排序；未分组资料使用独立栏。
  • 新增“调整布局”，支持每行 1–4 个分组、拖动或上下按钮调整分组顺序；按钮位于 List / Group 切换左侧。
  • Group 模式保留名称搜索与类型筛选，隐藏分组、Flow、Task 和最近常用筛选；复选删除、资料编辑、上传和下载继续适用。
  • 布局模式、每行分组数和分组顺序写入 JSON 数据偏好，导出备份并恢复后继续沿用。

稳定性

  • 资料勾选采用原位状态更新，连续选择或取消不会把页面或组内滚动位置带回顶部。
  • 语言切换继续固定在主导航后的统一位置，资料库布局控件独立靠右，不改变其他主页面页头。
  • Task 与资料库 Excel 模板、上传结构及全部报告格式均未改变，并继续通过 Windows-safe OOXML 校验。
v2.5 中英双语版 2026-08-12

在不改变 v2.4 数据结构和业务机制的前提下，为整套程序、文档及 Excel 输入输出增加完整中英文切换。

新增与调整

  • 在资料库右侧增加 Chinese / EN 切换，整套 UI、弹窗、提示、使用说明和更新日志随语言切换。
  • Task 与资料库模板、可回导数据、看板报告及人员状态报告自动使用当前界面的语种。
  • GitHub 项目主页提供中文与英文 README，并为两种语言分别配置对应界面配图。
  • 英文导入继续兼容中英文表头和值，不翻译或改写用户录入的业务数据。

稳定性

  • 继续沿用 Windows-safe XLSX 打包，模板与报告不含宏、外部链接、数据连接或默认冻结窗格。
  • 保留时间轴勾选、分组/Flow 展开折叠及资料库复选时的滚动位置保护。
  • 继续沿用 weekflow-v2.4:* 数据命名空间，升级 v2.5 不迁移、不清空用户数据。
v2.4 Week / Day 双时间轴版 2026-08-10

在原周时间轴基础上增加单周日粒度下钻，保持分组、Flow、Task 和既有导入导出逻辑不变。

新增与调整

  • 原时间轴主界面更名为 Task by Week，继续保留周范围浏览、回到本周、全部范围及全部展开折叠。
  • 双击任意周日期框可进入该周 Task by Day；表头按周一至周日显示日期和星期，Task DDL 标签落在具体日期列。
  • Task by Day 只显示在所选自然周内存在 DDL 的 Task；周期 Task 按该周的实际 DDL 参与筛选，其他周 Task 不显示。
  • 日视图保留分组、Flow、Task、筛选、编辑、完成和展开折叠功能，并以“返回 Task by Week”替代周范围控制。
  • 正式版升级为独立 v2.4 存储空间并自动迁移 v2.3 及更早版本；Excel 模板、上传和下载格式均未改变。

稳定性

  • Task by Week 与 Task by Day 均沿用被操作 Task 行锚点；在长列表底部勾选或取消完成后不会跳回首个分组。
  • 从日视图返回周视图会恢复进入前的周时间轴滚动位置；从其他主页面重新进入时间轴时默认回到 Task by Week。
v2.3 周期任务与临期提醒版 2026-08-08

建立每周、每月周期 Task 的连续完成模型，加入临期提醒，并强化批量回导与 Windows Excel 兼容。

新增与调整

  • 周期 Task 支持每周或每月模式，并要求填写周期开始和结束日期；DDL 作为星期或月内日期锚点，季度周期已移除。
  • 一个周期 Task 只保存和统计为一条记录，时间轴会在周期范围内展开全部 DDL 标签，不再克隆多条 Task。
  • 勾选当前自然周或自然月完成时，会把本期及此前各期一并视为完成；进入下一周期后自动恢复未勾选，连续完成历史继续保留。
  • Task 导入模板和可回导当前数据升级为 20 列，新增周期、周期开始、周期结束和周期完成记录；旧 16 列文件仍可导入。
  • 三类看板报告统一增加周期及起止日期，周标签区分已完成、逾期和待完成。
  • 进入程序时右下角显示未来 7 天未完成 DDL 提醒，10 秒后自动关闭；悬浮提醒不阻断操作，并采用新的图形化关闭按钮。
  • 移除未采用的 Flow 模板入口、弹窗与数据结构，保留 Flow 创建、编辑和步骤拖动排序。
  • 正式版升级为独立 v2.3 存储空间，并自动迁移 v2.2、v2.1、v2.0、v1.1 和 v1.0 数据。

优化与修复

  • 修复点击任意 Task 完成框后时间轴跳回顶部的问题；重绘前后会锁定被操作 Task 的视口位置和横向滚动位置。
  • 修复 Windows 显示缩放触发 1280px 响应式断点后，时间轴新建按钮停留在中部、资料库操作按钮另起一整行的问题；资料库标题和整组操作在桌面宽度下保持同一行。
  • 修复较早开始的周期 Task 在完成本期后，此前标签仍显示逾期的问题；旧的间断完成记录会在启动时自动补齐。
  • 可回导 Task 数据与资料库下载会移除无实际宏却可能触发 Windows“启用内容”的伪宏标记，并显式设置文档安全级别为 0。
  • 数据 v3 将周期设置和按期完成历史保存在 Task 内；JSON 备份恢复会校验周期范围和完成记录，旧式周期规则与 Flow 模板字段可安全读取并忽略。

v2.0 正式版本 2026-07-31

资料协同升级版本，把时间轴中的链接统一为可筛选、可统计、可双向编辑的资料库。

新增

  • 新增与时间轴、整体看板并列的资料库模块。
  • 资料支持说明文档、交付物、控制表、文件夹四种类型及多 Task/Flow/分组关联。
  • 新增资料库顶部搜索/筛选栏、最近常用统计、手动录入及 Excel 导入导出。
  • 时间轴“说明文档/交付物”合并为“相关资料”，编辑后实时同步资料库。
  • 资料 Excel 支持补充导入、重复地址替换或跳过，以及双重确认的全部覆盖。
  • 资料列表支持表头全选当前结果、复选和双重确认批量删除。

优化与修复

  • 旧版 Task 内链接自动迁移为 v2.0 统一资料，保留类型与 Task 归属。
  • 资料名称、地址、类型和关联关系从任一入口修改后保持同一数据源。
  • 最近常用改按本自然周和上个自然周统计，任一周打开过一次即可保留。
  • 资料关联改为“分组 → Flow → Task”级联选择，并移除备注搜索、重复全选和操作列。

v1.0 首个正式版本 2026-07-30
