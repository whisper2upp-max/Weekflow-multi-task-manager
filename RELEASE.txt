Weekflow v2.6
Release date: 2026-08-14

Document Library dual-layout release: 2026-08-14
- List preserves the existing full document table, filters, editing, selection, upload, and download behavior.
- Group displays fixed-height Task Group cards in a four-column default grid; extra Groups wrap to later rows and each card scrolls independently.
- Group documents show selection, document name, and a Go to action, sorted by current/previous natural-week open count and then by name.
- Arrange Layout sits to the left of the List / Group switch, supports one to four columns, and reorders Groups by dragging or move buttons.
- Group mode keeps document-name search and Type filtering while Group, Flow, Task, Recently Used filters remain List-only.
- JSON export and restore preserve the layout mode, columns per row, and custom Group order.
- The language switch remains immediately after Document Library on every page, independent of the right-aligned layout controls.
- Document selection remains an in-place update so long List and Group views do not jump to the top.
- Excel templates, upload schemas, and report structures are unchanged and retain Windows-safe OOXML packaging.

Bilingual interface release: 2026-08-12
- English is the default; Chinese remains available from the language switch beside Document Library.
- UI, guides, templates, re-importable data, Document Library exports, dashboard reports, and people reports follow the selected language.
- This is a language-and-documentation release. Business data structures and functional mechanisms remain identical to the v2.4 baseline.
- Chinese and English README pages link to each other and use language-matched screenshots.
- All seven Excel download paths use the selected language: both blank templates, re-importable current Task data, Document Library data, dashboard report, Managed Person report, and Report To report.
- Automated regression covers Task by Week/Day completion, Group/Flow collapse, individual document selection, 1280px Windows-width alignment, and strict XLSX package reopening.

This is the clean release build.
- No sample groups, Flows, Tasks, or documents are bundled.
- The restore-sample-data action and sample-data generator are not included.
- The release uses an isolated weekflow-v2.4:* browser storage namespace.
- Existing Weekflow v2.3/v2.2/v2.1/v2.0/v1.1/v1.0 browser data is migrated to data v3 and left intact for rollback.
- User data is stored locally in the browser.
- Blank Task and Document Library Excel templates are included.
- The main timeline is named Task by Week and retains the existing week-window, current-week, all-range, filtering, Group, Flow, and Task controls.
- Double-clicking any week header opens Task by Day for that natural week. The seven columns show Monday through Sunday with exact dates and weekdays, and each DDL node lands on its actual date.
- Task by Day shows only Tasks with a DDL occurrence inside the selected week, including generated weekly/monthly occurrences. It replaces week-range controls with a Return to Task by Week action.
- Returning from Task by Day restores the prior Week timeline scroll position. Completing or reopening a Task in either view preserves the operated row and does not jump to the first Group.
- Excel templates, imports, downloadable re-import data, Document Library workbooks, and dashboard-report formats retain their existing data structure.
- Tasks can recur weekly or monthly between required start/end dates. One stored Task renders every scheduled DDL from its anchor weekday/day-of-month; short months clamp safely to month-end.
- Checking the current natural week/month marks that occurrence and every earlier occurrence complete. The next period starts unchecked while the continuous earlier history remains stored, and the same Task is counted only once. Legacy gapped histories are repaired automatically.
- Quarterly recurrence and the unused Flow-template UI/data model have been removed. Existing Flow creation, editing, and Task step ordering remain unchanged.
- A non-modal bottom-right reminder lists incomplete Tasks due within seven days on every app entry and closes automatically after ten seconds; its close control now uses a polished drawn icon.
- JSON backup and restore validates Task-level recurrence dates and completion history while safely ignoring legacy top-level recurring-rule and Flow-template fields.
- Task data can be downloaded in the same 20-column import-template format and uploaded again, including recurrence cadence, start/end dates, and completion history. Legacy 16-column files remain accepted.
- Task Excel import supports supplement mode and double-confirm complete replacement while retaining the Document Library and matching hierarchy IDs.
- The timeline action is named "Export dashboard report" to distinguish the presentation workbook from re-importable Task data.
- The overall dashboard keeps only the five top-level metrics visible on entry and reveals Group, Flow, managed-object, or report-to summaries through four mutually exclusive buttons.
- Managed-object and report-to views provide progress cards, exact tables, and one-click per-object Task status workbooks sorted by Group with DDL, progress, deliverables, and related documents.
- Report-to and managed-object values are documented and demonstrated as person names in the Task form and Excel template.
- Dashboard and per-person Task status workbooks include recurrence fields and status-aware timeline markers, and open with no frozen panes on either worksheet.
- Dashboard-report OOXML includes the workbook-level AutoFilter name and standard Windows Excel workbook metadata; it contains no VBA, external workbook links, or data connections.
- Re-importable Task data and Document Library downloads are repackaged without SheetJS's unused macro-enabled content marker or workbook code name, and explicitly set document security to zero for Windows Excel compatibility.
- Expanding or collapsing an individual Group/Flow preserves the operated row, timeline horizontal position, and page scroll position.
- Completing or reopening any Task now preserves the operated Task row, timeline horizontal position, and page scroll position instead of jumping to the first Group.
- At Windows display-scaling breakpoints, timeline create-actions stay at the far right while the Document Library title and action group remain on one row without horizontal page overflow.
- Selecting or clearing individual documents updates selection controls in place without rebuilding the table or resetting its scroll position.
- The Document Library supports Group → Flow → Task cascading relations, two-way Task linkage, natural-week recent-use filtering, supplement/overwrite import, and double-confirm bulk deletion.
- Timeline filters share one high-contrast popover style and auto-close when another menu or blank page area is clicked.
- The timeline-only command bar is hidden on the overall dashboard.
- Document search and filters live in a dedicated bar above the table; document names edit in place and URLs open directly.
- The document editor uses a compact two-row details area so Group, Flow, and Task relations keep most of the dialog space.
- Document table headers, type, Flow, Group, and notes use the same 12px primary size as document names; URLs and related Tasks stay compact.
- The in-app changelog shows the full v2.6, v2.5, v2.4, v2.3, v2.2, v2.1, v2.0, v1.1, and v1.0 history in descending version order.
- The user guide identifies Weekflow as a Multi-task management cockpit and records the Wesley Yan development attribution plus first/latest release dates.
- Urgency, report-to, and deliverable are required for new or edited Tasks.
- Start with: open Weekflow.html directly, or run npm run serve and visit /Weekflow.html
- Keep the whole release folder together; Weekflow.html depends on its css, js, templates, and vendor directories.
