# v3.2 批量操作与归档试验

本分支基于 v3.2，只增加批量修改和批量归档，沿用原版界面。版本号暂不变更，未合并到 main，也不发布正式版本。

## 使用入口

- 时间轴工具栏 → **批量操作**。
- 顶部导航 → **已归档**。页面内可切换“当前工作 / 已归档”。
- 选择 Task、Flow 或分组层级，再搜索、按分组筛选。Task 还支持完成状态和周期类型筛选。
- 支持逐项选择和全选当前结果；筛选改变会清空选择，避免误操作隐藏记录。

## 批量修改

选择 Flow / 分组时，修改其未归档的下级 Task。

- DDL：设置同一天，或按正负天数平移。
- 紧急程度：高、中、低；也可保持原值。
- 管理对象：替换、清空或保持原值。
- 点击“预览修改”核对逐项前后值，再“确认应用”。取消预览不会写入数据；修改表单会使旧预览失效。
- 周期 Task 支持批量调整紧急程度和管理对象。其 DDL 仍需逐条编辑，以核对周期范围和完成记录；批量改期遇到周期 Task 会阻止整批操作。可先筛选“非周期 Task”。

## 归档与恢复

- Task、Flow、分组都可以多选归档；归档父级会同时归档其当前未归档的下级内容。
- 归档不会把未完成任务标记为完成。确认前显示影响范围及未完成 Task 数量。
- 归档内容退出时间轴、主页任务统计、整体看板、人员看板报告和临期提醒。资料库仍保留全部资料与关联。
- 已归档视图可以搜索、查看任务详情、进度和资料，以及批量恢复。
- 恢复父级会恢复随该次操作归档的下级；此前单独归档的子项继续保留在归档区。
- 归档父级仍在时，子项需先恢复父级，再单独恢复。
- 周期任务归档期间不再自动推进显示状态，恢复后按当前日期重新计算。

## 数据兼容

- 老 JSON 中没有归档字段的记录默认未归档。JSON 备份保留全部层级、归档批次、进度及资料关联。
- 可回导 Excel 保留原有 20 个业务字段，新增 6 个默认隐藏的归档信息列。旧模板仍可导入。
- 完整覆盖时，旧模板缺少归档信息会沿用匹配记录的归档状态；新导出的文件按所携带的归档信息恢复。
- 补充导入若匹配父级的归档状态不同，会拒绝整批导入，避免修改既有项目的归档状态。
- Excel 仍以 Task 为行，空分组 / 空 Flow 的完整备份继续使用 JSON。
