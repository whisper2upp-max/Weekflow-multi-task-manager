# v3.3 批量操作与归档

v3.3 在 v3.2 的功能基础上增加看板直接复选、批量修改、完成、删除和归档，沿用原版界面与数据存储。

## 使用入口

- 在 **Task by Week / Task by Day 看板**点击“批量选择”，再在任务行左侧复选；上方操作栏可批量修改、完成、删除或归档，不需要跳到另一张列表。
- 顶部导航 → **已归档**，用于查看和批量恢复。返回 Task 看板即可继续复选当前任务。
- 看板默认复选 Task；操作栏的“复选层级”也可切换为 Flow 或分组，直接勾选对应层级的行。沿用看板原有筛选条件。
- 日常模式只显示完成按钮；点击“批量选择”后，显示复选框与紫色操作栏，并隐藏完成按钮。点击“退出多选”或应用批量修改后恢复日常模式；退出不修改完成状态。
- “全选可见行”只选择当前筛选后、已展开的行；筛选改变会清空选择，折叠隐藏或离开当前日视图的行会从选择中移除。
- Flow / 分组作为整体被选中时，预览会列出受影响的下级记录；这包含该父级下被折叠或筛选隐藏的 Task。修改、完成和归档作用于未归档子项；永久删除则包含已归档子项。

## 批量修改

选择 Flow / 分组时，修改其未归档的下级 Task。

- DDL：设置同一天，或按正负天数平移。
- 紧急程度：高、中、低；也可保持原值。
- 管理对象：替换、清空或保持原值。
- 点击“预览修改”核对逐项前后值，再“确认应用”。取消预览不会写入数据；修改表单会使旧预览失效。
- 周期 Task 支持批量调整紧急程度和管理对象。其 DDL 仍需逐条编辑，以核对周期范围和完成记录；批量改期遇到周期 Task 会阻止整批操作。可取消所选周期 Task 后再批量改期。

## 批量完成与删除

- 批量完成：预览后确认，将所选未完成 Task 标记完成。已完成任务保持原完成日期；选中 Flow / 分组时处理其未归档下级 Task。
- 周期 Task 沿用单条完成规则：完成本期并补齐此前各期，未来尚未开始的周期跳过。预览列出当期 DDL 及跳过原因，跨日期后须重新预览。
- 批量删除：预览列出将永久删除的记录和进度历史，勾选确认后才可执行。删除 Flow / 分组包含其全部下级记录（含已归档项）。
- 资料库条目和随手记保留，仅清除资料对已删除 Task / Flow / 分组的关联。取消不写入数据；预览后数据或资料关联发生变化时，须重新预览。
- 弹窗内容过长时在内容区滚动，标题、关闭按钮和底部操作始终可见；窄窗口的字段自动换行。

## 归档与恢复

- Task、Flow、分组都可以多选归档；归档父级会同时归档其当前未归档的下级内容。
- 归档不会把未完成任务标记为完成。确认前显示影响范围及未完成 Task 数量。
- 归档内容退出时间轴、主页任务统计、整体看板、人员看板报告和临期提醒。资料库仍保留全部资料与关联。
- 已归档视图可以搜索、查看任务详情、进度和资料，以及批量恢复。
- 恢复父级会恢复随该次操作归档的下级；此前单独归档的子项继续保留在归档区。
- 归档父级仍在时，子项需先恢复父级，再单独恢复。
- 周期任务归档期间不再自动推进显示状态，恢复后按当前日期重新计算。

## 数据兼容

- 老 JSON 中没有归档字段的记录默认未归档。JSON 备份保留全部层级、归档批次、进度及资料关联。
- 可回导 Excel 保留原有 20 个业务字段，新增 6 个默认隐藏的归档信息列。旧模板仍可导入。
- 完整覆盖时，旧模板缺少归档信息会沿用匹配记录的归档状态；新导出的文件按所携带的归档信息恢复。
- 补充导入若匹配父级的归档状态不同，会拒绝整批导入，避免修改既有项目的归档状态。
- Excel 仍以 Task 为行，空分组 / 空 Flow 的完整备份继续使用 JSON。

## 资源更新与缓存验证

- CSS / JavaScript 地址携带文件内容的 SHA-256 摘要，避免新 HTML 混用旧缓存脚本或样式。资源更新不更改本地数据存储键。
- 修改 CSS / JavaScript 后运行 `npm run assets:version`，将更新后的 `Weekflow.html` 与资源一起提交；`npm test` 会检查摘要是否匹配，防止忘记更新。
- 2026-09-10 在用户已有 Chrome 标签页复现“已选 2 条，但完成/删除仍禁用”。更新资源地址并普通刷新后，两项操作均可打开对应预览，编辑弹窗的字段、关闭和底部按钮完整显示。只打开预览后取消，未提交任务完成或删除。
- 先前回归只覆盖新建浏览器上下文，未覆盖已有页面的资源缓存。后续验证应同时检查已有标签页的更新路径。
